🖨️ Printer Setup — Two Separate Printers

Most restaurants use two different printers: one at the counter for customer receipts, and one in the kitchen for order tickets (KOT). Set each printer's paper width here so every print comes out sized correctly for that exact printer -- the app can't pick which physical printer to use for you (your tablet/browser's print screen always asks you to choose), but it will label each print job clearly ("Receipt" vs "KOT") and size the paper correctly for whichever printer you choose.

⚡ Auto-Print (Skip the Print Picker) — Android

Normally every "Print" tap opens your device's print screen and asks you to pick a printer, every single time -- no webpage/app can silently choose a printer for you, that's an Android/OS rule, not something this app controls. RawBT is a free print-service app that works around this: once it's set up, it can accept the ticket directly and print it without showing that picker.

One-time setup per device:
1. Install RawBT from the Play Store.
2. Open RawBT, pair/select this device's printer inside the app, and do a test print from RawBT itself to confirm it works.
3. Turn the checkbox above ON. Tap "Save All Settings" at the bottom of this page.
4. From now on, Print / KOT on this device sends straight to that printer -- no picker.

For a separate counter printer + kitchen printer that both auto-print with no picker: use two devices, one at each station (e.g. a phone/tablet at the counter, another in the kitchen). Set up RawBT on each device pointed at that station's own printer, and turn this toggle on for both. The counter device's Print button already uses the Receipt paper-width profile above, and the kitchen device's KOT button already uses the Kitchen paper-width profile -- so each device just needs its own RawBT connected to its own printer. One single device genuinely cannot silently auto-route between two different physical printers -- that's a hardware/OS limit, not this app.

If this is off, or if RawBT isn't detected as working, Print/KOT falls back to the normal print picker automatically -- nothing breaks.

🖨️ How to Print (from a Tablet)

Tapping "Print / Save PDF" on a receipt opens your tablet's normal print screen -- the printer itself has to be set up on the tablet first, one time only:

Android tablet:

1. Pair your printer over Bluetooth (or connect it to the same WiFi, if it's a network printer).
2. Most cheap thermal printers need a small "print service" app to work with Android -- RawBT (free on the Play Store) works with almost any Bluetooth thermal printer. If your printer has its own official app, that works too.
3. Turn it on: Android Settings → Connected devices → Printing → enable RawBT (or your printer's service).
4. Tap "Print / Save PDF" here, pick your printer from the list, and print. (Or turn on Auto-Print above to skip this step every time.)

iPad:

iPads print directly (no app needed) only if the printer is AirPrint-certified and on the same WiFi. Most cheap thermal receipt printers are NOT AirPrint printers -- if yours isn't, use the "Share Photo" or "Download Photo" button next to Print instead, and send that receipt image into your printer's own app.

Desktop / laptop (Windows or Mac):

A browser on a computer has the exact same rule -- it always opens the print dialog and asks which printer to use, it can't silently pick one either. The closest equivalent to Auto-Print on desktop is a one-time Chrome shortcut with the --kiosk-printing flag, which skips the dialog and prints straight to whichever printer is set as that computer's default:
1. Right-click your Chrome shortcut → Properties → in "Target", add a space then --kiosk-printing at the end.
2. In Windows Settings → Printers, set the printer you want this computer to use as the default printer.
3. Open the app through that shortcut -- Print will now go straight to that default printer with no dialog.
For a counter PC + a separate kitchen PC, do this on both machines, each with its own printer set as its own default -- same one-printer-per-station idea as the two-device RawBT setup above, just for desktops instead of phones/tablets.

Either way, set the Receipt/Kitchen Printer Width above (58/60/80mm) to match your actual paper roll first, so the receipt prints at the right size.
